Configuración de la extensión

URL base del servidor FastAPI. Debe terminar con /.
El endpoint utilizado será {URL}predictions.

Obligatoria. Se envía como cabecera X-API-Key y se guarda solo en este navegador.

¿Cómo usar la extensión?
1. Abrí un correo en Gmail.
2. Seleccioná el texto que querés analizar.
3. Hacé clic derecho y elegí "Detectar phishing".
4. El resultado aparecerá en una ventana emergente.
DISCLAIMER
El contenido enviado es almacenado en la base de datos para futuros entrenamientos. Si el texto es sensible, es responsabilidad del usuario no compartirlo.
